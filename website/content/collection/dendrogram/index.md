A radial phylogenetic dendrogram of the whole collection, clade → order → family → genus → species. Each leaf carries source, status and, where photographed, a slideshow that opens on hover. The tree is built offline and published as a self-contained page; drag to pan, scroll to zoom, click anywhere to focus, Esc to clear.

Built with [D3.js](https://d3js.org/). The dataset is generated from the master Excel inventory; every photograph is watermarked CC BY-SA 4.0.
